## 本次会议概览

会议同步了决策模型和 PoL2 工程工作的进展。成员汇报，决策模型准确率已提升至约 80%，并通过多个维度的泛化验证；后续需要补充高风险和不确定样例，再训练并交付权重文件。团队还讨论了将大语言模型的证据提取与 Prolog 的规则推理分开：模型负责从文本中抽取与爱、恨有关的具体行为证据，Prolog 根据明确规则作形式化裁决。

PoL2 评测方面，团队指出现有硬边界存在重复计数，也未覆盖公平、平等、普惠等正向行为表现。下一步需要明确各边界适用的主体和触发阈值，并据此形成新版规范。

## 项目进展与讨论

### 1. 决策模型训练与交付

团队汇报，决策模型从早期约 43% 的基线、此前约 60% 的水平提升至目前约 80%。成员称，模型在多个理论维度上都有提升，并使用多维度验证检查泛化表现；最终采用的随机数种子为 17。

当前仍需重点补充模型难以判断的样例，尤其是高风险或不确定选项。完成补充训练后，计划将模型权重上传 GitHub 供团队测试，调用方式沿用 KTV 本地 API 格式。

**下一步：**补齐高风险和不确定数据，继续训练并检查表现；之后上传权重文件。

### 2. 大语言模型与 Prolog 的混合治理

会议讨论了混合治理方案的职责分工：

1. **大语言模型提取证据。**从文本中定位与爱、恨有关的具体行为证据，不承担全量语义裁决。
2. **Prolog 执行规则推理。**将抽取出的证据交给 Prolog，依据预设规则进行形式化推理和裁决，以便规则可以被检查和调整。

会议提出，为精简当前的治理逻辑，可将爱、恨特征概括为三组对照：爱侧重平等、普惠（互利）与公共；恨侧重不平等、巧取豪夺与私有。会议还表示，当前治理裁决暂不纳入人类复杂的主观情感体验。上述概括属于会议讨论的特征提取思路，仍需与规范文本和实现方案对齐。

团队同时指出两类工程风险：MCP 本身主要执行脚本函数，缺乏语义理解能力；由大语言模型把非形式化文本转成形式化事实时，也可能出现遗漏或幻觉。因此，混合方案仍需验证事实抽取质量和裁决链路。

### 3. PoL2 评测与硬边界规范

会议认为，现有 9 条硬边界存在重复计数问题，其中 H-07 与 H-09 的语义有重叠；同时，仅覆盖禁止事项的硬边界，尚不能完整呈现 PoL2 对公平、平等、普惠等行为表现的评估要求。

为区分不同事实来源，会议已讨论把 H-07 拆为 A、B 两种情形：模型主动捏造事实，以及模型转述第三方未经核实的说法。新版规范仍需进一步明确每条边界的适用主体、触发阈值及重叠时的计数方式，再交由 GPT 团队生成和审阅新版本。

**当前定位：**会议确定了规范扩展和去重方向；边界的最终定义与评测操作细则仍待完善。

### 4. 低神经元生物决策与 MCP 基准测试

会议分享了低神经元生物（讨论中举例果蝇、线虫）的决策研究：这类生物可通过突触积分和状态更新，对外界刺激作出快速反应，并表现出习得性条件反射。该部分作为理解简化决策机制的研究参考。

团队还汇报了 Prolog 与 MCP 的基准测试观察：若向规则系统提供人工预设的准确事实，测试准确率可达 100%；若事实依赖大语言模型抽取，准确率会明显下降。该结果提示后续工程需要单独评估事实抽取质量，并记录从原始文本到形式化事实的转换过程。以上为会议汇报的测试结果，尚未在本文中独立复算。

## 会议结论与推进方向

1. 决策模型下一轮训练优先补足高风险和不确定样例，再交付权重供团队试用。
2. 混合治理采用“证据提取—规则裁决”的分工作为待实现和验证的方案。
3. 修订硬边界时，处理 H-07 与 H-09 的重复计数，并补充适用主体、触发阈值及正向行为评估覆盖。
4. 评估模型将非形式化文本转成规则事实时的准确性与幻觉风险，保留可复核的证据链。
