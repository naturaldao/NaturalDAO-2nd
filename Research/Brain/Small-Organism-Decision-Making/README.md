# 小生物如何形成动作决策

研究问题：蚂蚁、果蝇等小神经系统，以及没有神经元的单细胞生物，如何从感知和内部状态形成有效行动？

**核心发现：**神经元数量不足以解释行为。现有研究支持专用回路、时间积分、记忆读出、局部反馈与身体环境耦合；单细胞则通过生化、膜电和形态动力学完成其中一些功能。动作选择不要求先具备语言或意识。
